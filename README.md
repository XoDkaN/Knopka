Как это работает
1. Запустите сервис:
bash
python knopka.py
2. Управление через URL (просто введите в браузере):
Включить кнопку:
http://localhost:5000/knopka_on

Выключить кнопку:
http://localhost:5000/knopka_off

Проверить статус:
http://localhost:5000/knopka_status

Переключить (инвертировать):
http://localhost:5000/knopka_toggle

3. Особенности:
✅ Работает прямо из адресной строки — просто вводите /knopka_on или /knopka_off

✅ Автоматическое перенаправление — после ввода URL вы вернетесь на главную страницу

✅ Работает и через GET, и через POST — максимальная совместимость
